# Changelog

## 1.2.3 - 2026-11-01

### Changed

- New versions are now built and uploaded to CurseForge automatically. The addon itself is unchanged.
- Releases are now tagged automatically.

### Fixed

- A release bug kept version 1.2.1 from reaching CurseForge.

## 1.1.0 - 2026-10-31

### Added

- **Move UI elements**: a preview circle for placing the queue eye
- **Point and bar class resources**: an Enable switch on each page that turns all of its resources on or off at once
- **Cursor position**: a single-color ring as an alternative to the two-tone ring, with its own color and width
- **Cursor position**: the inner and outer trackers can each be turned off

### Changed

- **Player position**: the Manual offset checkbox is now a Position dropdown (Dynamic or Manual). Offset sliders only show in Manual mode. Your previous choice carries over.
- Previews are now buttons instead of checkboxes and turn off when you close the options
- Settings pages are tidier: class checkboxes, cross styling and ring sections are grouped under headers, and options for turned-off parts are hidden

## 1.0.0 - 2026-10-11

First public release.

### Added

- **Hide UI elements**: hide the loot window, bag icons and the player frame's group indicator
- **Move UI elements**: move the queue eye onto the minimap, and move the Battle.net toast anywhere with a placement preview
- **Filter chat**: mute the "You have learned/unlearned" spam when swapping talent loadouts
- **Point class resources**: move runes, combo points, essence, chi, soul shards, arcane charges and holy power to screen center, with shared offset and scale
- **Bar class resources**: custom center-screen bars for rage, energy, focus, fury, runic power, insanity, maelstrom, astral power, Ebon Might and Soul Fragments, with optional spec-flavored textures
- **Player position**: a cross marking your character at screen center that follows camera zoom, with optional combat-only mode
- **Cursor position**: a two-ring circle following the cursor, with radial trackers for spell casts and the global cooldown
